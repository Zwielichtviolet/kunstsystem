Kunstsystem — «Рупор искусства»
1. О проекте

Kunstsystem — это интерактивный справочник изобразительных стилей, оформленный в эстетике компьютерного терминала. Проект опубликован по адресу https://zwielichtviolet.github.io/kunstsystem/, исходный код доступен в репозитории https://github.com/N-Strar/kunstsystem. Лицензия — MIT, см. файл LICENSE.

Сайт представляет собой одностраничное приложение: переходы между стилями происходят без перезагрузки страницы, состояние навигации хранится в хэше адреса, а пользовательские настройки — в localStorage.
2. Языки и технологии

Проект построен на HTML5, CSS3 и JavaScript в версиях ES5/ES6 без сторонних библиотек. HTML5 отвечает за семантическую структуру страницы, мета-теги для SEO, карточки Open Graph и Twitter. CSS3 реализует весь визуальный стиль: анимации, сетки, адаптивность, спецэффекты и таймлайн. JavaScript отвечает за всю логику: роутинг, командную строку, лайтбокс и работу с localStorage. Данные каталога хранятся в data.js в виде JSON-подобной структуры: стили, годы, описания, художники и работы. Для хранения кода и версионирования используется Git и GitHub, для публикации — GitHub Pages с автодеплоем из ветки main.

Внешние зависимости отсутствуют: нет фреймворков, CDN и шрифтовых сервисов. После первой загрузки сайт работает даже при отключённом интернете.
3. Структура проекта

Проект состоит из файла index.html — каркаса страницы с SVG-favicon, Open Graph/Twitter-тегами и подключением скриптов; style.css — всех стилей и анимаций, включая таймлайн; data.js — данных каталога стилей (DATA) и карты годов (YEARS); script.js — логики приложения: роутинга, CLI, лайтбокса и localStorage; LICENSE — лицензии MIT; папки img/ — 36 изображений, включая картины и фон BD.jpg.
4. Назначение файлов
4.1. index.html

index.html — это каркас приложения. В <head> указаны кодировка UTF-8, адаптивный viewport, meta description для поисковиков и подключение style.css. Там же размещён SVG-favicon в data-URI: зелёный терминальный текст на тёмном фоне, без внешних файлов. Добавлены Open Graph и Twitter Card теги (og:title, og:description, og:image → img/BD.jpg и другие), чтобы ссылка красиво выглядела в соцсетях и мессенджерах. В шапке расположен терминальный блок .terminal-header с «кнопками» macOS и заголовком окна. Основная часть страницы — пустой контейнер <main id="screen">: всё содержимое строит JavaScript. Скрипты data.js и script.js подключаются с атрибутом defer, чтобы данные загружались перед логикой. Такой подход превращает сайт в одностраничное приложение.
4.2. style.css

style.css отвечает за всё оформление. Для body задан фон страницы: фото img/BD.jpg и затемняющий градиент для читаемости; терминал центрируется. Псевдоэлемент body::after создаёт CRT-эффект: полупрозрачные строки развёртки поверх всего экрана. Окно терминала .terminal имеет полупрозрачный фон (86%) и backdrop-filter: blur(), поэтому фон просвечивает. Блок .term-dual реализует «магию двойного текста»: немецкий и русский текст наложены через CSS Grid (grid-area: 1/1), немецкий сдвинут и затемнён — получается эффект глитча. .timeline строит вертикальную линию, годы слева и названия стилей справа; при наведении строка подсвечивается. Также описаны мигающий курсор .cursor и @keyframes blink, стили командной строки .cmd-input и .cmd-output, сетка картин .image-grid и .image-card в две колонки, полноэкранный лайтбокс .lightbox, каскадное появление блоков .reveal и @keyframes fadeUp.

Изображения .art-image получают лёгкий фильтр «старения» (grayscale + sepia); при наведении цвет возвращается, а картинка приближается. Используется ленивая загрузка loading="lazy". Медиазапрос @media (max-width: 600px) делает карточки в одну колонку, уменьшает заголовки и делает таймлайн компактным. Для доступности добавлены @media (prefers-reduced-motion: reduce), отключающий анимации, и :focus-visible — видимая рамка при навигации с клавиатуры.
4.3. data.js

data.js содержит только данные, без логики. Здесь правится контент сайта. Массив DATA — каталог стилей из 18 объектов. Каждый объект включает slug — имя для адреса страницы (#impressionismus), de — немецкое название, ru — русское название, tb — описание в виде HTML-строки, artists — список художников и works — массив работ с полями src, alt, caption.

Объект YEARS — карта годов: соответствие «slug → год возникновения стиля», от Готики около 1150 года до Цифрового искусства 1990 года. Эти данные используются таймлайном в меню и командой timeline.
4.4. script.js

script.js содержит логику приложения. Роутинг (route, renderIndex, renderStyle) следит за хэшем адреса: #bauhaus строит страницу стиля, пустой хэш — главное меню со списком стилей и таймлайном. На странице стиля отображается год возникновения. Открытый стиль запоминается в localStorage под ключом ks_last_slug, поэтому в меню появляется ссылка «открыть снова».

Таймлайн (renderTimeline) сортирует стили по годам из YEARS и строит интерактивную хронологическую ленту в главном меню.

Командная строка (bindCli, COMMANDS) обрабатывает ввод пользователя. Поддерживаются команды: ls или l — список всех стилей; open <№ или имя> с сокращениями op, cd — открыть стиль, например op 13; timeline или tl — стили по годам возникновения; random с сокращениями zufall, rnd — открыть случайный стиль; cat beschreibung.txt — прокрутка к описанию; index или menu, а также m — вернуться в главное меню; whoami или w — «кто я»; date — текущие дата и время; clear или cls — очистить вывод; hilfe с сокращениями h, help — справка. Стрелки ↑ и ↓ листают историю команд. Неизвестная команда получает ответ в стиле bash: bash: …: команда не найдена.

История команд сохраняется в localStorage под ключом ks_cmd_history, до 50 последних команд; стрелки ↑/↓ работают как в настоящем терминале.

Лайтбокс (openLightbox) открывает картину на весь экран по клику; закрывается кликом или клавишей Esc.

Вспомогательные функции: esc() экранирует HTML, reveal() запускает каскадную анимацию, findStyle() ищет стиль по номеру, немецкому или русскому названию с нормализацией умлаутов, lsGet() и lsSet() безопасно работают с localStorage и не ломаются в приватном режиме.
4.5. img/

В папке img/ находятся 36 изображений. BD.jpg — фон страницы за окном терминала и превью для Open Graph. Также здесь 26 картин классических стилей (Моне, Дали, Уорхол, Баухаус и другие) и 10 картин новых стилей (Ренессанс, Барокко, Классицизм, Модерн, Абстракционизм). Если изображение отсутствует, обработчик onerror заменяет его терминальной заглушкой [ signal fehlt ], поэтому сайт не ломается без картинок.
5. Архитектура

Браузер загружает index.html, который подключает style.css, data.js и script.js. В data.js находятся DATA с 18 стилями и YEARS с годами. Функция route() читает адрес: при пустом хэше вызывается renderIndex() и строится меню с таймлайном и ссылкой «открыть снова», при хэше вроде #bauhaus вызывается renderStyle() и строится страница стиля с годом. События обрабатывают клики по ссылкам, ввод команд с историей и клик по картине для лайтбокса.

Состояние навигации хранится в адресе страницы, поэтому ссылку на конкретный стиль можно скопировать и отправить, а кнопка «назад» браузера работает как в обычном многостраничном сайте. Пользовательские настройки — последний стиль и история команд — хранятся в localStorage.
6. Этапы разработки

Версия 1 работала на Netlify и была многостраничным сайтом: 14 HTML-файлов и общий style.css. Были обнаружены и исправлены дефекты: задвоенный <head> в expressionismus.html, неверные alt-тексты у 8 изображений и дублирование правил в CSS.

Версия 2 на GitHub Pages стала результатом рефакторинга в одностраничное приложение. Проект разделили на index.html, style.css и script.js; появились интерактивная командная строка с сокращёнными командами, полноэкранный просмотр картин, фон страницы и полупрозрачное окно терминала с размытием, CRT-эффект и каскадные анимации. Каталог расширился с 13 до 18 стилей. Также были добавлены доступность (focus-visible, prefers-reduced-motion, aria-атрибуты) и SEO (meta description).

Версия 3 — текущая. Данные вынесены из script.js в отдельный data.js (DATA и YEARS). Появились таймлайн «стили по годам» в главном меню и команда timeline/tl, команды random/zufall/rnd для случайного стиля, история команд в localStorage с навигацией стрелками ↑/↓, запоминание последнего стиля (ks_last_slug) и ссылка «открыть снова» в меню. Добавлены SVG-favicon в data-URI, Open Graph/Twitter-теги с og:image → img/BD.jpg, ленивая загрузка картин loading="lazy" и лицензия MIT.
7. Итоги

В проекте на практике применены HTML5 — семантическая разметка, мета-информация, Open Graph/Twitter-карточки и SVG-favicon; CSS3 — Grid, фильтры, backdrop-filter, keyframes-анимации, медиазапросы и кастомные эффекты вроде CRT, глитч-текста и таймлайна; JavaScript — работа с DOM, события, hash-роутинг, обработка ввода, localStorage и доступность; Git/GitHub — версионирование и публикация через GitHub Pages. Проект демонстрирует полный цикл: от концепции и дизайна до хостинга и документирования.
