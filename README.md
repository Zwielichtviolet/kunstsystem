# Kunstsystem — «Рупор искусства»
## Техническая документация проекта

**Проект:** интерактивный справочник изобразительных стилей в эстетике компьютерного терминала.
**Адрес:** https://n-strar.github.io/kunstsystem/
**Репозиторий:** https://github.com/N-Strar/kunstsystem

---

## 1. Концепция проекта

Справочник знакомит с 18 направлениями изобразительного искусства — от Готики до Цифрового искусства. Каждый стиль представлен на отдельной «экранной странице» в виде выдачи компьютерного терминала: команды, ответы системы, моноширинный шрифт, эффект CRT-развёртки.

Ключевая особенность — **двуязычность**: немецкий и русский текст наложены друг на друга со сдвигом (эффект «призрачного глитча»), что отражает немецкоязычную тематику курса.

Сайт полностью статический: не требует сервера, базы данных и сборки. Работает в любом современном браузере.

## 2. Использованные языки и технологии

| Технология | Роль в проекте |
|---|---|
| **HTML5** | Семантическая структура страницы, мета-теги для SEO |
| **CSS3** | Весь визуальный стиль: анимации, сетки, адаптивность, спецэффекты |
| **JavaScript (ES5/ES6, без библиотек)** | Вся логика: данные, роутинг, командная строка, лайтбокс |
| **JSON** (встроенная структура данных) | Каталог стилей, описания, художники, работы |
| **Git + GitHub** | Хранение кода, версионирование |
| **GitHub Pages** | Бесплатный статический хостинг, автодеплой из ветки `main` |

Внешние зависимости отсутствуют: ни фреймворков, ни CDN, ни шрифтовых сервисов — сайт работает даже при отключённом интернете после первой загрузки.

## 4. Назначение файлов

### 4.1. `index.html` — разметка (HTML5)

Каркас приложения. Содержит:

- `<head>`: кодировка UTF-8, адаптивный viewport, `meta description` для поисковиков, подключение `style.css`;
- шапку терминала `.terminal-header` с «кнопками» macOS (красная, жёлтая, зелёная) и заголовком окна;
- пустой контейнер `<main id="screen">` — всю содержимую часть страницы строит JavaScript;
- подключение `script.js` с атрибутом `defer` (скрипт стартует после разбора разметки).

Такой подход (пустой контейнер + JS-рендеринг) превращает сайт в **одностраничное приложение (SPA)**: переходы между стилями происходят без перезагрузки страницы.

### 4.2. `style.css` — оформление (CSS3)

Ответственность по секциям:

| Секция CSS | Что делает |
|---|---|
| `body` | Фон страницы: фото (`img/BD.jpg`) + затемняющий градиент для читаемости; центрирование терминала |
| `body::after` | CRT-эффект: полупрозрачные строки развёртки поверх всего экрана |
| `.terminal` | Окно терминала: полупрозрачный фон (86%) + `backdrop-filter: blur()` — фон просвечивает |
| `.term-dual` | **Магия двойного текста**: немецкий и русский текст наложены через CSS Grid (`grid-area: 1/1`), немецкий сдвинут и затемнён — эффект глитча |
| `.cursor`, `@keyframes blink` | Мигающий курсор |
| `.cmd-input`, `.cmd-output` | Стили командной строки и ответов системы |
| `.image-grid`, `.image-card` | Сетка картин: две колонки, тень, скругления |
| `.art-image` | Лёгкий фильтр «старения» (`grayscale + sepia`); при наведении цвет возвращается, картинка приближается |
| `.lightbox` | Полноэкранный просмотр картины: затемнение на весь экран, картинка по центру, подпись |
| `.reveal`, `@keyframes fadeUp` | Плавное каскадное появление блоков при загрузке |
| `@media (max-width: 600px)` | Адаптивность: одна колонка карточек, уменьшенные заголовки |
| `@media (prefers-reduced-motion: reduce)` | Отключение анимаций для пользователей с ограниченной подвижностью (доступность) |
| `:focus-visible` | Видимая рамка при навигации с клавиатуры (доступность) |

### 4.3. `script.js` — данные и логика (JavaScript)

Ядро приложения. Структура:

**1) `DATA` — каталог стилей (JSON).**
Массив из 18 объектов. Каждый объект:

```javascript
{
  slug: "impressionismus",   // имя для адреса страницы (#impressionismus)
  de: "IMPRESSIONISMUS",     // немецкое название
  ru: "ИМПРЕССИОНИЗМ",       // русское название
  tb: "<p>…</p>",            // описание (HTML-строка)
  artists: ["Клод Моне (Claude Monet)", …],
  works: [ { src, alt, caption }, … ]  // картины
}
```

Контент сайта правится только здесь — вёрстку трогать не нужно.

**2) Роутинг (`route`, `renderIndex`, `renderStyle`).**
Следит за хэшем адреса: `#bauhaus` → строит страницу стиля, пустой хэш → главное меню. Навигация работает кнопками «назад/вперёд» браузера.

**3) Командная строка (`bindCli`, `COMMANDS`).**
Обрабатывает ввод пользователя. Поддерживаемые команды:

| Команда | Сокращение | Действие |
|---|---|---|
| `ls` | `l` | список всех стилей |
| `open <№ или имя>` | `op`, `cd` | открыть стиль (напр. `op 13`) |
| `cat beschreibung.txt` | — | прокрутка к описанию |
| `index`, `menu` | `m` | вернуться в главное меню |
| `whoami` | `w` | «кто я» |
| `date` | — | текущие дата и время |
| `clear` | `cls` | очистить вывод |
| `hilfe` | `h`, `help` | справка |

Неизвестная команда получает ответ в стиле bash: `bash: …: команда не найдена`.

**4) Лайтбокс (`openLightbox`).**
Клик по картине открывает её на весь экран; закрытие — клик или клавиша `Esc` (обработчик клавиатуры добавляется и снимается корректно).

**5) Вспомогательные функции.**
`esc()` — экранирование HTML (защита от поломки вёрстки спецсимволами); `reveal()` — каскадная анимация появления; `findStyle()` — поиск стиля по номеру, немецкому или русскому названию (с нормализацией умлаутов: `ä→ae`, `ü→ue`, `ß→ss`).

### 4.4. `img/` — изображения

- `BD.jpg` — фон страницы за окном терминала;
- 26 картин классических стилей (Моне, Дали, Уорхол, Баухаус и др.);
- 10 картин новых стилей (Ренессанс, Барокко, Классицизм, Модерн, Абстракционизм).

Отсутствующее изображение заменяется терминальной заглушкой `[ signal fehlt ]` (обработчик `onerror`) — сайт не «ломается» без картинок.

## 5. Как это работает (архитектура)

```
Браузер
  │
  ├── index.html ──► подключает style.css и script.js
  │
  ├── script.js: DATA (18 стилей) ──► route() читает адрес
  │                                        │
  │                    ┌───────────────────┴──────────────────┐
  │                    ▼                                      ▼
  │              #пусто → renderIndex()              #bauhaus → renderStyle()
  │              строит главное меню                 строит страницу стиля
  │
  └── события: клики по ссылкам, ввод команд, клик по картине (лайтбокс)
```

Состояние приложения хранится в адресе страницы (хэш), поэтому ссылку на конкретный стиль можно скопировать и отправить, а кнопка «назад» браузера работает как в обычном многостраничном сайте.

## 6. Этапы разработки и улучшения

**Версия 1 (Netlify).** Многостраничный сайт: 14 HTML-файлов, общий `style.css`. Обнаружены и исправлены дефекты: задвоенный `<head>` в `expressionismus.html`, неверные `alt`-тексты у 8 изображений, дублирование правил в CSS.

**Версия 2 (GitHub Pages, текущая).** Рефакторинг в одностраничное приложение:
- разделение на `index.html` / `style.css` / `script.js`;
- интерактивная командная строка с сокращёнными командами;
- полноэкранный просмотр картин (лайтбокс);
- фон страницы + полупрозрачное окно терминала с размытием;
- CRT-эффект, каскадные анимации;
- расширение каталога с 13 до 18 стилей;
- доступность (`focus-visible`, `prefers-reduced-motion`, aria-атрибуты) и SEO (`meta description` на каждой странице).

## 7. Итоги

- **HTML5** — семантическая разметка и мета-информация;
- **CSS3** — Grid, фильтры, backdrop-filter, keyframes-анимации, медиазапросы, кастомные эффекты (CRT, глитч-текст);

Проект демонстрирует полный цикл: от концепции и дизайна до хостинга и документирования.
